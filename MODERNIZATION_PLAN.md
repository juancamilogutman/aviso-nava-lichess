# Modernization Plan: Lichess Activity Tracker

This document outlines the transition from a Git-based, email-reliant tracker to a modern serverless architecture using **Telegram** for instant alerts and **Upstash Redis** for state management.

## 1. Architectural Changes

### Current Approach (Git Scraping)
- **State:** `state.json` committed to the repository.
- **Alerts:** Email via SMTP (Gmail).
- **Triggers:** GitHub Actions cron job.
- **Workflow:** Action runs -> Fetches Lichess -> Reads Git state -> Sends Email -> Commits new state.

### Modern Approach (Serverless + Instant)
- **State:** [Upstash Redis](https://upstash.com/) (Free Tier). A high-speed, serverless Key-Value store. No more "bot" commits in your Git history.
- **Alerts:** [Telegram Bot API](https://core.telegram.org/bots). Instant push notifications to your phone.
- **Scripting:** Node.js (TypeScript) for faster execution and native GitHub Actions support.

## 2. Requirements & Secrets

Before implementing, you will need to gather the following:

### A. Telegram Setup
1. Message [@BotFather](https://t.me/botfather) on Telegram.
2. Create a new bot and copy the **API Token**.
3. Message [@IDBot](https://t.me/myidbot) to get your **Chat ID**.
4. *Secrets to add to GitHub:* `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

### B. Upstash Setup
1. Create a free account at [upstash.com](https://upstash.com/).
2. Create a Redis database (Global or regional).
3. Copy the **REST URL** and **REST TOKEN**.
4. *Secrets to add to GitHub:* `UPSTASH_REDIS_URL`, `UPSTASH_REDIS_TOKEN`.
